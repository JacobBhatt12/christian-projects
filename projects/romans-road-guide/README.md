# The Romans Road

An interactive black-and-white guide for sharing the gospel using the Romans
Road — five verses from the book of Romans, stepped through one at a time,
each paired with a short line of what to say. A separate tab holds a closing
prayer to use when someone is ready to respond.

## Usage

Just open `index.html` in a browser — no install, no build step. Use the
Back/Next buttons or the dots to move between verses, and "Copy" to grab the
verse or prayer text.

## Requirements

None — plain HTML, CSS, and vanilla JavaScript.
