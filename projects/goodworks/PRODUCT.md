# GoodWorks

## Register

product

## Users

Small nonprofits, churches, and Christian ministries recording activities and preparing impact reports, as described in README.md.

## Product Purpose

A local browser workspace for accurate attendance, volunteer hours, supplies, and donor-facing reports.

## Brand Personality

Clear, practical, calm. Use the Zenith dashboard reference provided by the user, with neutral light and dark appearances based on user preference.

## Anti-references

Avoid decorative color that competes with reporting data and any theme that assumes all users prefer the same lighting.

## Design Principles

- Keep counting definitions and local storage behavior explicit.
- Preserve familiar dashboard navigation and workflows.
- Follow device appearance by default and remember manual preferences.
- Keep reports readable when printed.

## Accessibility & Inclusion

Preserve existing keyboard navigation, labeled controls, responsive layouts, and reduced-motion support. Theme changes must include forms, dialogs, charts, and error states.
