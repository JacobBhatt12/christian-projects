# Bible Trivia Quiz

A multiple-choice Bible trivia game that runs in the terminal.

## What it does

- Asks 15 questions about well-known Bible stories and facts
- Shuffles the question order every time you play
- Tells you the right answer when you miss one
- Shows your final score with a short message at the end

## Usage

```bash
python3 bible_trivia_quiz.py
```

Answer each question by typing `a`, `b`, `c`, or `d`.

## Requirements

Python 3 only, no downloaded requirements needed.
