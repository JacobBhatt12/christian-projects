# Prayer Request Tracker

This is a small Python project I made to keep track of prayer requests from the
terminal. The requests are saved in a JSON file, so they will still be there
the next time the program is opened.

## Features

- Add a new prayer request
- See all prayer requests
- Mark a prayer as answered
- Save the date a prayer was added and answered

## How to run it

Open a terminal in this folder and run:

```bash
python3 prayer_request_tracker.py
```

The program will show a menu. Type the number for the option you want and press
Enter.

The prayer requests are stored in `prayer_requests.json`. You do not need to
edit that file yourself because the program updates it for you.

## Requirements

You only need Python 3. There are no extra packages to install.
