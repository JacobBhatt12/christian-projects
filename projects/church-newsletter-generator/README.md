# Church Newsletter Generator

A browser app for building a church newsletter, styled after an old
mimeographed Sunday bulletin — typewriter type, a rubber date stamp, a bit of
photocopied grain on the paper. Fill in the pastor's note, upcoming events,
and prayer list, and watch the bulletin on the right type itself out live.

## Features

- Fields for a church name, pastor's note, upcoming events, and a prayer list
- Add or remove as many events or prayer requests as you need
- Live preview that updates as you type, styled like a real printed bulletin
- "Stamp & download" saves a formatted `newsletter.txt` to your computer
- "Print this copy" prints just the bulletin, not the form

## How to run it

Just open `index.html` in a web browser. No install or server needed.

```bash
open index.html
```

## Requirements

Just a modern web browser. No extra tools or packages required.
