# Sermon Notes Organizer

A small web app for keeping track of sermon notes. Each note saves the date,
speaker, topic, and what you wrote down, so you can look back on what you
learned later. Notes are saved right in your browser, so they will still be
there the next time you open the page.

## Features

- Add a new sermon note with a date, speaker, topic, and your notes
- See all sermon notes, most recent first
- Search past notes by keyword, with matches highlighted in the speaker,
  topic, or notes text
- Delete a note you no longer need

## How to run it

Just open `index.html` in a web browser. No install or server needed.

```bash
open index.html
```

Notes are saved using your browser's local storage, tied to this page. If you
clear your browser data or open the page in a different browser, your notes
won't carry over.

## Requirements

Just a modern web browser. No extra tools or packages required.
