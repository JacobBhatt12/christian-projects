# The Lamb of God

A little app for tracing one thread through the Bible instead of reading
verses on their own — ten stops, Abel's sacrifice all the way to the Lamb
on the throne in Revelation.

Click a stop and it opens up: the scripture, the history behind it, why it
connects to the one before it, and a question to sit with.

Everything in it was written by hand, not generated — you can find it in
`src/data/lambOfGod.ts`. Scripture is KJV.

## Running it

```bash
npm install
npm run dev
```

Then open the link it prints (usually `http://localhost:5173`).
