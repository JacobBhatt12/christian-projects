# Scripture Flashcards

A Python terminal flashcard quiz for memorizing Bible verses.

## What it does

- Stores 15 verse reference/text pairs (KJV, public domain)
- Shuffles the cards and shows you one reference at a time
- You recite or type your guess, then press Enter to reveal the verse
- You grade yourself (y/n) and it tracks your score
- Shows your final score and percentage at the end

## Usage

```bash
python3 scripture_flashcards.py
```

Press `Ctrl+C` to end early — your score so far is still shown.

## Requirements

Python 3 only, no downloaded requirements.
