# Belong Here

Belong Here is a warm, mobile-first church discovery and newcomer connection prototype. It helps someone find a church, plan a first visit, discover an approachable next step, and connect safely through church-approved groups and ambassadors.

## Prototype flows

- Church discovery with search, filters, list, map, and five realistic church profiles
- Three-step “I’m New” onboarding and personalized newcomer dashboard
- Visit planning, parking, childcare, accessibility, and first-time QR check-in
- Event discovery, saving, registration, and reminders
- Small groups with life-stage filters and private join requests
- Safe introductions, private messaging, blocking/reporting affordances, and verified ambassadors
- Family profile, prayer privacy choices, notifications, and accessibility preferences
- Separate church administrator dashboard for visits, care, content, safety, and aggregate analytics

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173`.

## Verify

```bash
npm run lint
npm run build
npm test
```

The end-to-end tests cover the main newcomer journey, event registration, connection request, admin portal, and desktop/mobile layouts.
