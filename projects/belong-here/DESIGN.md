# Belong Here Design System

## Theme

A strict monochrome app surface. White and soft-gray backgrounds, near-black text, black actions, grayscale photography, and sharp corners keep the interface direct and utilitarian.

## Color

- Canvas: `oklch(97.5% 0 0)`
- Surface: `oklch(99.5% 0 0)`
- Ink: `oklch(18% 0 0)`
- Muted ink: `oklch(45% 0 0)`
- Border: `oklch(86% 0 0)`
- Primary action: `oklch(20% 0 0)`
- Selected surface: `oklch(92% 0 0)`

## Typography

- UI and body: system sans-serif, 400–700
- Mobile body: 15–16px with 1.55 line height

## Layout and Components

- Plain text app name with no brand logo
- Mobile-first shell with five-item bottom navigation and a compact desktop rail
- Primary buttons are near-black with a 48px minimum height
- Inputs have 48px minimum height and a visible focus ring
- All controls, cards, panels, chips, and avatars use square corners
- Compact cards are reserved for distinct churches, events, groups, and next steps
- Photography is grayscale and used only when it helps identify a church, group, or event

## Motion

Use 180–240ms opacity and transform transitions, with reduced-motion support.

## Voice

Friendly, specific, and low-pressure. Use “You can,” “If you’d like,” and “We’ll help you know what to expect.”
