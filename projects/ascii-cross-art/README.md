# ASCII Cross Art

A simple Python terminal app that prints an ASCII art cross with a random
encouraging Bible verse underneath.

## What it does

- Prints a decorated ASCII cross to the terminal
- Picks a random encouraging verse (KJV) and prints it centered below the cross
- Different verse every time you run it

## Usage

```bash
python3 ascii_cross_art.py
```

## Requirements

Python 3 only, no downloaded requirements needed.
