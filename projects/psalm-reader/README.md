# Psalm Reader

A quiet terminal reader for Psalms 23, 91, and 100 in the King James Version.

## Usage

```bash
python3 psalm_reader.py
```

Choose a psalm by entering `23`, `91`, or `100`. The verses appear one at a
time with a short pause between them. Press `Ctrl+C` at any time to close the
reader.

## Requirements

Python 3 only. No downloaded packages are needed.

The included Scripture text is from the public-domain King James Version.
