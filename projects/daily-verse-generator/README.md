# Daily Verse Generator

A beginner-friendly Python terminal app that chooses one of 20 Bible verses at
random and displays it in a colorful bordered card.

## Run it

You need Python 3 installed. Open a terminal in this project folder, then run:

### macOS or Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 daily_verse.py
```

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py daily_verse.py
```

Run the final command again whenever you would like another verse.

## Content source

The included verses use the public-domain King James Version (KJV).
