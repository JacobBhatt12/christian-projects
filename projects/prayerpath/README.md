# PrayerPath

> Remember every prayer. Recognize every answer.

A small, quiet prayer journal. Write down what you're praying for, sort it into a
few plain categories, come back to it as often as you want, and mark it answered
when God moves — with a note about how. Answered prayers move into a simple
history so they don't get forgotten.

There's no account and no server. Everything is saved to your browser's local
storage, on this device only.

## What's in it

- A short homepage explaining what the app is for
- Your list of active prayers, filterable by category (family, health, church,
  work, gratitude, other)
- A form for adding and editing a prayer, with a private note field for your
  own thoughts
- A "mark as answered" flow that asks how it was answered
- A history page of everything that's been answered so far

The app comes pre-loaded with a few example prayers on first run so it doesn't
feel empty — edit or delete them once you've added your own.

## Running it

```bash
npm install
npm run dev
```

Then open the link it prints (usually `http://localhost:5173`).

## Built with

React, TypeScript, Tailwind CSS, and Vite.
