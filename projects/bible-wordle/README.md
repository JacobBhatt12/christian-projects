# Scripture Wordle

A Bible-themed take on Wordle. Guess the 5-letter word in 6 tries — names,
places, and words drawn from Scripture (GRACE, MOSES, ISAAC, SINAI, and more).
When the round ends, it shows you the word along with a short verse or note
about where it comes from.

## Usage

Just open `index.html` in a browser — no install, no build step.

Type letters, hit Enter to submit a guess (or use the on-screen keyboard).
Tiles turn green for a correct letter in the right spot, and amber for a
correct letter in the wrong spot.

## Requirements

None — plain HTML, CSS, and JavaScript.
