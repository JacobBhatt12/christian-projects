# Jacob's Christian Projects

Hi, I'm Jacob. I enjoy building Christian-focused apps and creative coding
projects that help share Scripture, encourage faith, and make biblical content
easy to explore.

This repository is the home for all of my Christian projects. Every project is
kept in its own folder with its complete source code and a README explaining
what is needed to install and run it. More projects will be added as I continue
learning, creating, and finding new ways to use technology for God's glory.

To use a project, open the `projects` folder, choose one, and follow the
instructions in its README. You can view the code directly on GitHub or select
**Code** and then **Download ZIP** to download the repository to your computer.
