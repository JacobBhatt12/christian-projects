# Jacob's Christian Projects

Hi, I'm Jacob. I enjoy building Christian-focused apps and creative coding
projects that help share Scripture, encourage faith, and make biblical content
easy to explore.

This repository is the home for all of my Christian projects. Each project has
its own folder containing the complete source code and a README with everything
you need to understand, install, and run it.

## Explore the projects

| Project | What it does |
| --- | --- |
| [Daily Verse Generator](projects/daily-verse-generator/) | Displays a randomly selected KJV Bible verse in a colorful terminal card. |

More projects will be added over time. You can also browse the complete
[projects directory](projects/).

## How to use a project

### Browse it on GitHub

1. Open the [`projects`](projects/) folder.
2. Choose a project.
3. Read that project's `README.md` for its requirements and instructions.

### Download and run it

1. Select the green **Code** button near the top of this repository.
2. Choose **Download ZIP**, then extract the downloaded file.
3. Open the `projects` folder and select the project you want.
4. Follow the instructions in that project's `README.md`.

You can also clone the complete repository:

```bash
git clone https://github.com/JacobBhatt12/christian-projects.git
cd christian-projects/projects
```
