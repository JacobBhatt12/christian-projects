## Add a new project

1. Create a folder under `projects/` using a short, lowercase name with hyphens.
2. Give the project its own `README.md` with its purpose and setup steps.
3. Add the project to the table above.
4. Keep secrets, API keys, private messages, and account-export metadata out of
   Git.

## Security

Never commit passwords, tokens, private keys, personal data, or populated
environment files. Dependency updates are monitored by Dependabot. Please read
the [security policy](SECURITY.md) before reporting a vulnerability.
