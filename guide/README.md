# Guide for Christian Coders

This folder is separate from [`projects`](../projects). `projects` holds finished
apps you can run. `guide` is for people who are earlier in the journey —
students learning to code, career-changers, or anyone who wants practical
help getting into the field, written from a Christian perspective on work
and calling.

- [Learning to Code](learning-to-code.md) — where to start, what to actually
  practice, and how to avoid tutorial paralysis.
- [Building a Portfolio](building-a-portfolio.md) — how to turn small
  projects (like the ones in this repo) into proof you can build things.
- [Resumes & Job Search](resume-and-job-search.md) — resume structure,
  what to put in a coding resume with little or no experience, and how to
  talk about projects in interviews.
- [Staying Encouraged](staying-encouraged.md) — on rejection, comparison,
  and working "as unto the Lord" when the job search is discouraging.

This folder also has small terminal tools, not just writing:

- [`roadmap-cli`](roadmap-cli) — a curated map of learning resources for
  each stage of the journey (beginner, intermediate, professional). Run
  `roadmap` to browse it.
- [`focus-cli`](focus-cli) — a terminal companion for purposeful coding
  sessions, prayer, and reflection. Run `focus` to use it.

> “Whatever you do, work heartily, as for the Lord and not for men.”
> — Colossians 3:23 (ESV)

None of this is expert career advice — it's what I've learned and gathered
while building the projects in this repo. Treat it as a starting point, not
a rulebook.
